### **Africa Disaster Impact Predictor**

A machine learning project used to analyze historical disasters and estimate disaster-related deaths using the EM-DAT dataset.
This project is intended for academic and research purposes. Predictions are estimates based on historical data and should not be treated as official disaster forecasts.
